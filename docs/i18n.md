# Languages

The app shows its words in English or Simplified Chinese. **Settings → Appearance → Language**
chooses, per device; **System** follows the device's own language (any Chinese reads Simplified
Chinese). Choosing reloads the page. dot answers in the language you write to it in, whatever the
app shows. Messages the daemon writes (errors it explains, the Mac's and phone's notifications,
release notes) are still in English.

## How a message is written

`apps/web/src/i18n/index.ts`. The English, written where it is used, is both what English shows and
the message's key; another language is a catalog of translations of those keys
(`apps/web/src/i18n/zh-CN/`, one file per part of the app). The language's catalog loads as
`i18n/index.ts` does, and every module that asks for a message waits for it there, so a word a
module fixes as it loads is in it too.

- ``t`Saved ${count} files` `` for a message, values in their places. In the catalog the key is
  `Saved {0} files`, values numbered in order.
- `tr("Done")` for words kept as a plain string, such as a value in a table of names. Write the words
  in the call itself: the check below finds messages by reading the source.
- ``rich`Press ${<Kbd>⌘K</Kbd>} to search` `` for a message with elements inside it. It returns nodes,
  not a string.
- `tc("button", "Reset")` for the same English that needs different words by where it stands, such
  as Reset the button (重置) and Reset the state (已重置). The catalog keys it `[button] Reset`.
- `count(n, "step", "steps")` (`copy/format.ts`) for a number and its noun. The catalog keys the
  English pair as `step|steps` and gives the whole phrase, `#` for the number: `# 个步骤`.

Write whole sentences, never a sentence put together from translated pieces: word order differs
between languages. A sentence with a number in it is one message with the number as a value; `count`
is for a number and its noun standing alone.

What is not for the reader stays as it is: class names, ids, keys, event names, log lines, test ids,
URLs, values the daemon or a model reads, and what is sent to dot as the user's words.

## Translating

Natural, short Simplified Chinese, as Apple's own apps say it: 你, not 您; Chinese punctuation
(，。？！：“”) in Chinese sentences; a space either side of a Latin word or a number. Names stay as they
are: dot, localDot, Claude, ChatGPT, Codex, Chrome, Chromium, Docker, Tailscale, Mac, macOS, GitHub
and other products and sites. A value (`{0}`) keeps its place in the sentence where Chinese puts it;
every value the English has must be in the translation, and a count's `#` too.

## The check

`apps/web/src/i18n/catalog.test.ts` reads every source file for `t`, `rich`, `tr`, `tc` and `count` and fails
when the catalog lacks a message, a translation drops a value, a key is in two catalog files, or the
catalog holds a message nothing asks for. Its failure lists each message with the file asking for it.
