## What's new

- On a phone, Studio's screen tucks into a corner as you read the conversation, and you can drag it to any corner or tap it to bring it back.
- On an iPhone Duo held upright, the conversation fills the screen and the list slides over it.
- On an iPhone Duo held sideways, Studio puts the computer beside the chat and the list slides over the computer.
- The tags over the list stay on one line, and All opens every tag in place with a search.

## Fixes

- On an iPhone Duo held sideways, the message box stays on the keyboard while you type in Studio.
- Scrolling through a long run of steps on an iPhone no longer jumps.
- The tags row no longer shows a scrollbar, and a long tag name slides along to show all of itself.
