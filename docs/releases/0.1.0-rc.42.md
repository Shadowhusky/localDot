## What's new

- The web browser now looks and works like a window on dot's desktop, with its own dock icon, a minimise button and Alt+Tab (Option-Tab on a Mac) to switch while you're in control.

## Fixes

- When a page in the web browser is busy, dot waits for it instead of failing, and says the web browser was slow rather than that the computer's screen couldn't be read.
- Sites that move on by themselves after opening, like Telegram Web, no longer make the web browser refuse the page and restart.
- A task that's still working is no longer shown as interrupted, with a Continue that can't go through.
- A busy Docker that's only slow to answer no longer shows "Docker isn't available".
- The screen stays on the web browser when dot's task there ends, instead of jumping back to the desktop.
