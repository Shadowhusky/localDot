## Fixes

- When a page in the web browser is busy, dot waits for it instead of failing, and a task that can't read the web browser at first starts on the desktop instead of stopping.
- If the web browser doesn't answer in time, dot says so, instead of saying the computer's screen couldn't be read.
- Pages nobody is using pause after a minute and resume the moment dot or you use or watch them, so a busy site left open no longer keeps your Mac working hard.
