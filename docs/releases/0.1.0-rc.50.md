## Fixes

- Stopping a task in its first moments no longer costs you the computer: the desktop's browser finishes getting ready for the task, and a task that ends before or after that leaves the computer in use.
- A computer held after a Claude Code or Codex task that never got to start can be replaced at once, instead of waiting for an exit that was never coming.
- When a computer is held because its desktop browser could not be made ready for a task, the log now says which check refused.

## Before you update

- The log's new detail arrives with each computer's next update.
