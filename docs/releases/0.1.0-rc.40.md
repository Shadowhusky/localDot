## What's new

- Chat and Studio: a messenger-style Chat view, the phone's default, beside the full Studio view; pick one in setup and switch any time on each device.
- Every task has its own dot, dressed for the job, and Auto picks the dot that fits.
- The web browser is now a window on dot's desktop, one window per task, all sharing your sign-ins.
- Choose a model for a whole task or for one message, from a library of your models in Settings.

## Fixes

- On a busy Mac, dot retries a dropped step without running it twice and waits out slow moments instead of restarting the browser.
- Replacing your computer keeps showing its progress while your files copy, instead of warning that it couldn't confirm.
- dot asks for a sign-in code only after the site has sent one, and requests a new code when an old one has expired.
- Plan usage in the model menu no longer shows a 5-hour limit that has already ended.
- Phone layout and gestures, conversation switching, menus, the live preview's corners and light and dark contrast are tidier.
