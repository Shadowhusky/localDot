## What's new

- Update now no longer gets stuck behind a task: it lists what is still going, then waits for it to finish or stops it all when you say so.

- When dot wants to remember something after it has read the web, it asks you with the exact words instead of giving up, and what you said yourself saves straight away.

## Fixes

- The steps name the model only where it really changes, not each time its provider calls it by another name.
- dot brings its plan up to date before it finishes a task, and the plan's progress is a small meter beside its count.
- A web app's preview opens from anywhere on its card, with one Open button and the rest in a menu.
- A press at the edge of a file or settings row now counts, and the row keeps its size while pressed.
- The web browser's dock icon shows only while that browser runs, and the last words of a chat rest above the fade over dot's line.
