## What's new

- dot's web browser now uses your computer's time zone and a standard English setup, so fewer sign-in pages mistake it for a robot.
- dot's web browser has the everyday fonts an ordinary computer has, so pages look the way they should.
- When a site won't let dot sign in, one clear button lets you sign in yourself, and dot stays signed in afterwards.
- The doctor check now tells you when localDot runs on a cloud server, where sign-in pages show more security checks.

## Before you update

- The web browser restarts once; your sign-ins stay.
