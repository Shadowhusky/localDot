## Fixes

- A new task no longer turns into an earlier one: when localDot changed the dot for a task just after it started, dot was told to continue a saved task, and could pick up one you had asked for before.
- dot can read and use busy pages, such as Douyin's login screen, on a busy computer: the browser's look at its own window has the time it needs instead of turning the page away.
- A slow screenshot on a busy computer no longer stops the web browser and closes its pages.
- A computer update that once stopped over files an installed app changed is tried again when localDot can now bring them across, instead of only offering Start fresh.

## Before you update

- The browser fixes arrive with each computer's next update.
