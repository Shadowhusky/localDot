## What's new

- Tag conversations with a colour, pin, archive or delete them, and search both their titles and what was said, in the list on the left.
- Hovering over the collapsed list magnifies it like the Dock and shows the names nearby.
- Choose how much memory and how many CPUs each dot's computer gets, in Settings or during setup.
- Pressing Stop before dot answers puts your message back in the box.

## Fixes

- The screen no longer flickers while a side panel opens, closes or changes width.
- dot keeps going when the model asks for a tool it can't use, and a task that has to stop names the tool.
- A hat no longer brushes the lower edge of the screen.
- Saving Settings no longer warns that the save couldn't be verified when it worked.
- A conversation's state in the list no longer slips back to an older one.

## Before you update

- Your computer keeps its current size until you change it.
