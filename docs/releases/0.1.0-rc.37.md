## What's new

- A message you send while dot is waiting now cuts the wait short, so dot reads it sooner.
- When Auto picks a dot after its quick wait, the pick still applies as long as dot hasn't started.
- After you switch to another localDot, it lists the one you came from, with its name and dot.

## Fixes

- The list on the left scrolls smoothly while it is magnified, and right-clicking anywhere on a conversation opens its menu.
- The buttons beside the message box no longer touch it when highlighted.
- Your dot wears its accessory everywhere, including in the line that says which dot is working.
- The model menu shows plan usage only for the plan the chosen model runs on.
- A preview beside the chat closes when you click outside it.

## Before you update

- To list each other, both localDots need this version.
