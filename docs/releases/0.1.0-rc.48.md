## Fixes

- dot no longer loses a page to the browser's own dialogs: a site that opens its desktop app (as Douyin, Zoom or Slack do) no longer brings up "Open xdg-open?", and Google Chrome no longer offers to translate pages.
- When one of the browser's own dialogs does cover a page, dot says so and asks you to close it, instead of calling the page busy and restarting the browser.
- A computer update no longer stops with "An installed app changed files needed by this update" after you have installed an app.
- In Chat, the sign-in offer under the screen is one short row lined up with the controls, and the screen makes room so nothing runs off the window.

## Before you update

- The browser fixes arrive with each computer's next update.
