## What's new

- Each conversation has one tag, and its row shows it as a colour beside the title.
- The tags over the list wrap onto more lines, and the rest wait under All tags.
- Sort into tags shows how far it has got, and works through a long list in batches.
- In Chat view the list of conversations can be made wider or narrower by dragging its edge.
- A file you attach opens in the preview before you send it, and a file that can't be previewed says so.

## Fixes

- localDot opens faster, loading each screen when it is first needed.
- A phone stays cooler and typing keeps up while dot works.
- A reply with a wide table stays on a phone's screen, and the table scrolls inside it.
- A message's menu opens under it at once, instead of appearing above it and jumping down.
- The rows of tags that scroll sideways no longer move up and down, and a mouse wheel scrolls them sideways.

## Before you update

- A conversation that had several tags keeps the last one it was given.
