# Controller rulings on the Part 2 plan's assumptions (2026-10-01)

- P2-R1: Accept vendoring Selkies' client from the pinned image and serving it from the daemon (MPL-2.0: ship its license text and a NOTICE with the source location); nothing a cell serves ever runs in the UI origin — a compromised cell cannot inject script into the control UI — cost if wrong: none.
- P2-R2: Accept per-cell stream tickets in the iframe path (the only cookie-free way an iframe can authorise), on these terms: minted only through an authenticated API call, ≥128-bit random, compared in constant time, never logged, scoped to one cell's stream, revoked on cell stop/remove and on daemon restart — cost if wrong: a leaked URL lets a local page view one cell's stream until it stops.
- P2-R3: Accept the own minimal Docker Engine client (API v1.47 over the Unix socket), Docker-chosen host ports on 127.0.0.1, static cell IPs, the stated resource limits and on-failure restarts ×3 — small surface, fake-socket testable — cost if wrong: swap in dockerode later behind the same interface.
- P2-R4: Accept plain CSS driven by the Theatre tokens for Part 2; Tailwind 4 + shadcn/ui (spec "Stack") arrive with the first component-heavy UI (M4 chat/timeline/settings). The token file must be shaped so Tailwind 4's `@theme` can consume it unchanged — cost if wrong: a small CSS migration.
- P2-R5: Do NOT defer the macOS look. Spec "Look" (desktop cell section) is part of the desktop image (M1), the user's original ask is a virtual window that looks like macOS/Linux, and the theme changes window/panel geometry that Part 3's mapping will measure. Part 2 adds it: WhiteSur (or MacTahoe) GTK theme + its xfwm4 xhdpi variant, WhiteSur icons, a Plank dock, the top panel styled as a menu bar — pinned (commit or sha256), MIT license recorded, consistent with the HiDPI pins at 2× and 1×, with screenshot checks; Task 15's acceptance screenshot shows it — cost if wrong: one extra task.
- P2-R6: Accept stall constants 500 ms pings / 1500 ms watchdog from Selkies' 0.2 s server ping; S8 may raise them — cost if wrong: a constant.
- P2-R7: Accept printing the `#token=` URL at daemon start as a development convenience; M9's `npx localdot` opens the browser instead — cost if wrong: the token appears in a terminal scrollback on the user's own Mac.
- P2-R8: Accept Chromium-maximized in Part 3 (app launch) and `SELKIES_ENCODER=h264enc` (S1's startup log names that encoder) — cost if wrong: none.
- P2-R9: Accept the e2e daemon on 4790 and the keyd relay targeting an unallocated port until M3 — cost if wrong: none.
- P2-R10: Accept the listed unverified items with S8 proving the stream first — cost if wrong: Task 4's fallbacks.
- P2-R11: Part 1's re-review residuals (Ruling 36) belong in Part 2's first daemon task: publish the lock with the pid inside (temp file + linkSync), treat the daemon's own pid as stale, handle SIGHUP, clear message for an unreadable lock; process managers run the daemon with node directly (pnpm does not forward SIGTERM) — cost if wrong: none.
- P2-R12: The desktop uses WhiteSur's LIGHT variant (GTK theme, xfwm4 `-hdpi`/`-xhdpi` builds, icons, Plank theme), not Dark — C: Theatre is a lit stage inside a near-black surround, and its overlay styling (xenon with a dark halo; contrast against Calc's selection blue) was tuned on white desktop content — overrides the review's `-c Dark` suggestion — cost if wrong: one install flag.
- P2-R13: Record each theme asset's actual license before pinning. If the WhiteSur icon theme is GPL-3.0, it ships as separately licensed data inside the image, like the GPL-3.0 linuxserver base (in-image license file + the repo notice); the spec's license line gets updated after execution — cost if wrong: none.
- P2-R14: Drop Docker's on-failure restart policy. The orchestrator restarts a failed container with backoff (spec) and re-reads its published ports after every start; add "a container restarted or recreated gets new host ports" to Review Focus — cost if wrong: none.
- P2-R15: A19's session metadata in the session folder is daemon work and lands in Part 2 as one small task on the event log; the other carries (stage PointerPlan import + curve switch, finite-input guards, overshoot cap, resizedPixels, envelope id ULID_PATTERN, observe images as files, confirming the Cua opt-outs on the wire, relay backpressure) are listed explicitly as Part 3 obligations in "Interfaces Part 3 builds on" — cost if wrong: none.
- P2-R16: Accept the restart counter resetting only on a user start/stop, so a flapping cell gives up after five automatic restarts and shows failed — prevents an endless restart loop — cost if wrong: the user restarts a cell that would have recovered on attempt six.
