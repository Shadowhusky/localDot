# @localdot/avatar-spine

An optional avatar renderer for Spine 4.3 rigs, built on spine-pixi-v8.

This package uses the Spine Runtimes, which are licensed under the Spine Runtimes License Agreement
(https://esotericsoftware.com/spine-runtimes-license). Integrating the Spine Runtimes requires a
valid Spine Editor license. localDot works without this package: the default mascot renderer in
`@localdot/avatar` has no such requirement.
