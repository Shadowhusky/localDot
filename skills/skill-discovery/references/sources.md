# Official starting points

Reviewed 2026-10-19. These are discovery links, not a claim that every package is installed or best for every task. Read current documentation, license and the chosen SKILL.md before installing. Prefer a pinned revision for reproducible work.

| Work | Sources | What to inspect |
| --- | --- | --- |
| Skill packaging | https://agentskills.io/specification | Progressive disclosure, relative resources and portable metadata |
| React/Next.js performance and component APIs | https://github.com/vercel-labs/agent-skills | react-best-practices, composition-patterns; match framework/version |
| UI, browser tests, MCP integrations | https://github.com/anthropics/skills | Selected licensed packs are bundled; other packs have different license terms |
| Browser regression testing | https://playwright.dev/docs/best-practices | Locators, isolation, assertions, traces and fixtures |
| Motion graphics and media production | https://github.com/heygen-com/hyperframes | Entry-point routing, targeted runtime/media/audio skills; inspect dependencies and render cost before installing |
| Debugging methodology | https://github.com/obra/superpowers | Root-cause investigation and evidence; adopt only a useful workflow, not automatic multi-agent or approval ceremony |
| React video | https://www.remotion.dev/docs/ai/skills and https://github.com/remotion-dev/skills | Motion/composition vs existing-footage editing, renderer requirements, runtime license |
| Video filtering and codecs | https://ffmpeg.org/ffmpeg.html and https://ffmpeg.org/ffmpeg-filters.html | Installed encoders, timestamps, color, audio filters |
| 3D work | https://docs.blender.org/manual/en/latest/ | Appropriate scene workflow and render-device limits |
| Accessible interaction | https://www.w3.org/WAI/ARIA/apg/ and https://www.w3.org/WAI/WCAG22/quickref/ | Native controls, keyboard patterns, target size, focus and contrast |
| Web performance | https://web.dev/articles/vitals | Real measurements and realistic device conditions |
| Data analysis | https://pandas.pydata.org/docs/ and https://duckdb.org/docs/ | Types, nulls, streaming/column selection and reproducibility |
| Statistical analysis | https://www.statsmodels.org/stable/ and https://docs.scipy.org/doc/scipy/ | Test assumptions, uncertainty, effect size and model diagnostics |
| Office documents | https://python-docx.readthedocs.io/ and https://openpyxl.readthedocs.io/ | Editable documents, formulas and recalculation limits |
| Figma designs | https://developers.figma.com/docs/ | Existing connector/API access and image export |
| API media generation | The configured provider’s official API documentation | Current model catalog, formats, editing support, polling and costs |

For a specific library or service not listed, search its official documentation and its maintained skill repository. Inspect contents before installing; popularity alone is not a quality or security guarantee. Ask for missing user-only configuration through the private input flow only after checking saved context and credential metadata.
