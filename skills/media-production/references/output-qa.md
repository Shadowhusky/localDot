# Check the actual deliverable

Images: inspect final pixels at the target size; check reference/mascot consistency, spelling, alignment, safe margins, contrast, cropping, alpha and export format. Verify dimensions with an image inspector. A polished preview is not proof the downloaded artifact is the same file.

Video: probe duration, resolution, frame rate, video/audio streams and codec. Inspect a contact sheet and playback around cuts, titles and the ending. Check audio audibility, clipping, music balance, caption timing and safe areas. Use a real encoded export for QA, not only the composition preview. Do not describe an unreadable timeline or blank browser as successful validation.

Documents/slides: render the actual PDF or deck and inspect every page for overflow, missing fonts, uneven spacing and unreadable charts. Include editable sources when requested.

Deliver the requested final files with meaningful names through `done.files`, including source/project files when useful. Keep temporary previews distinct. State relevant dimensions/duration and any unverified part, without claiming subjective “best” quality or unsupported performance improvements.
