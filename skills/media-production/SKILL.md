# Media production

Confirm the requested deliverable: audience, source assets, duration or dimensions, aspect ratio, language, editable source and export. Reuse supplied references and the product’s actual assets, especially recurring characters and logos. Check `work_context` and `credentials` metadata, then read [tool selection](references/tool-selection.md). Use `skill-discovery` to research and install a relevant specialist workflow when it would improve the result.

Make a proportional plan. For video, outline the sequence, timing, audio and visual treatment before rendering. For a cover or poster, settle the headline and hierarchy with real content before making variants. Research visual references when needed; do not invent brand assets or copy unrelated styles by default.

Choose the medium on its merits. Code is appropriate for diagrams, interface prototypes, charts and precise motion graphics. Existing footage needs an editing workflow. Photographic or illustrated assets may need a generation/editing API; do not approximate every asset with HTML shapes. Reuse available GUI tools when that provides a better editable result.

Prove the toolchain with one small output, inspect it, then create the full deliverable. Work in a task folder and preserve originals. Watch resource use during renders; use a small test size and limited workers on a constrained virtual computer. Finish with [output QA](references/output-qa.md) and return files with `done.files`; opening them on the desktop alone does not deliver them to the remote user.
